Abstract

A finite registration budget is exchanged among 200 registered structures. Run A (calibration): exchange only — no temperature exists anywhere in the code. Run B (machinery): maintenance, gradual erasure into cold storage, and merging with savings are added. A noise-driven intake stream supplies fresh candidates to the gate (A1→A2): most are rejected — P1, happening live — a minority pass and replenish the registry. The readouts test three claims live: (i) a Boltzmann distribution and an emergent temperature arise from budget bookkeeping alone (§8); (ii) the merging machinery renormalizes the emergent temperature while the books stay conserved and the Gibbs form survives (§8); (iii) across the compressor family, the gate's anchors — pure noise rejected, pure order admitted — are invariant while the blind spots move (§5, F5). Heat is accumulated as ΔQ = bits reclaimed × emergent temperature × ln 2 (A5′). An interpreter panel issues a good / broken verdict every frame.

Controls

Calibration mode reproduces Run A: budget exchange only, no temperature anywhere in the code — watch the Boltzmann histogram and the fitted exponential appear anyway. Machinery ON adds maintenance, gradual erasure (bits move to cold storage) and merging with savings — Run B. Temperature in the readout is the emergent mean budget W/M; the fitted T comes from the histogram slope alone.

Experiment bench — scripted runs + auto-balance

While an experiment runs, the bench drives merge/intake (sliders suspended). Experiment III runs a PI controller on the intake command: u = clamp(u₀ + Kp·err + Ki·∫err, 0, umax), err = M* − M. The controller is not told the gate's admission ratio (~10%) — the integral term must discover it online; the settled command u* therefore measures the gate's admittance (u* ≈ deaths / admission).
